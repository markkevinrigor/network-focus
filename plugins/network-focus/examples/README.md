# Practice files

Made-up company (Harbor Analytics) and made-up people, for trying Network Focus without real data.

| File | What it shows |
|---|---|
| `goals.md` | A filled-in goals file with three goals |
| `practice-roster.csv` | A normal roster. It contains two people named Morgan Lee, a note that mentions "Jordan at Kestrel Capital" (no such person on file), a goal organisation nobody works at (Harrow Capital), and a stated timing window ("let's revisit in a month"). The brief should flag all four. |
| `practice-roster-missing-column.csv` | The "Days Since Last Contact" column renamed to "Last touch". The brief stops with NF-03 and lists the columns it found. |

To try them: copy this folder somewhere, open Claude Code in it, and type `/network-focus:brief practice-roster.csv`.
